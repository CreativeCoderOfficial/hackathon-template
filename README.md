# Hackathon template

Next.js, Supabase, Tailwind and shadcn, organised by feature so four people and four agents can work in parallel.

Start with `CLAUDE.md`, then `docs/ARCHITECTURE.md` and `docs/HACKATHON.md`.

```
cp .env.example .env.local   # fill in the Supabase values
npm ci
npm run dev
```
